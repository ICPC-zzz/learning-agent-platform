开发预览入口

Books：/books

用于预览图书列表入口。

Learning：/learning

用于预览学习工作台入口。

Reader：/reader

必须提供 bookId，chapterId 可选。非法参数会回退到 /books。

Agent：/agent?mode=preview

仅允许固定 mode=preview。任意其他参数都会回退到 /books。

环境变量

  • LAP_DESKTOP_WEB_URL=http://localhost:3000
  • LAP_DESKTOP_WEB_ROUTE=/books 或 /learning 或 /reader 或 /agent
  • LAP_DESKTOP_READER_BOOK_ID（Reader 必填）
  • LAP_DESKTOP_READER_CHAPTER_ID（Reader 选填）
  • LAP_DESKTOP_AGENT_MODE（Agent 固定为 preview）

未设置 LAP_DESKTOP_WEB_URL 时，Desktop 默认加载本静态首页。

PowerShell 启动示例

示例仅用于本机开发预览，不包含任何真实密钥或数据库连接信息。

cd E:\code\learning-agent-platform
$env:LAP_DESKTOP_WEB_URL="http://localhost:3000"
$env:LAP_DESKTOP_WEB_ROUTE="/books"
npx electron apps/desktop
cd E:\code\learning-agent-platform
$env:LAP_DESKTOP_WEB_URL="http://localhost:3000"
$env:LAP_DESKTOP_WEB_ROUTE="/learning"
npx electron apps/desktop
cd E:\code\learning-agent-platform
$env:LAP_DESKTOP_WEB_URL="http://localhost:3000"
$env:LAP_DESKTOP_WEB_ROUTE="/reader"
$env:LAP_DESKTOP_READER_BOOK_ID="sample-book"
$env:LAP_DESKTOP_READER_CHAPTER_ID="chapter-1"
npx electron apps/desktop
cd E:\code\learning-agent-platform
$env:LAP_DESKTOP_WEB_URL="http://localhost:3000"
$env:LAP_DESKTOP_WEB_ROUTE="/agent"
$env:LAP_DESKTOP_AGENT_MODE="preview"
npx electron apps/desktop

  • nodeIntegration: false
  • contextIsolation: true
  • sandbox: true
