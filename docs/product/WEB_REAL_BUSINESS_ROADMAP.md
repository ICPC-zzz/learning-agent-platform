# Web 真实业务路线图

> 从 A374 起生效。本文件定义近期（Phase 1–6）Web 端真实业务开发的路线图、优先级和验收标准。

## 1. 路线图原则

- **Web 真实业务优先**：默认优先推进 Web 端真实用户功能。
- **Desktop 延后但非取消**：Desktop 端后续必须有用户界面，但应在 Web 主线更完整后再推进。
- **不再堆 preview 面板**：Desktop 已有 10 块只读本地预览面板，近期暂停继续新增。
- **每轮可含关联子任务**：同一业务链路下的多个关联子任务可在同一轮完成。
- **合规导入**：优先自写示例书 → 用户粘贴文本 → GitHub Markdown/开源内容；不默认乱爬网页。
- **真实能力接入有 guard**：DB/auth/LLM 接入必须单独任务、显式 guard、明确测试。

## 3. 第二阶段：真实用户系统与用户中心

**状态**：未开始（推荐 A375 起）

**目标**：建立真实的用户身份体系和用户中心页面。

| 任务 | 优先级 | 说明 |
|------|--------|------|
| 用户注册 / 登录 / session 管理 | P0 | 最小可用 auth 方案（NextAuth 或类似） |
| 用户中心页面骨架 | P0 | `/user` 或 `/me` 路由，各模块占位 |
| 最近阅读列表 | P1 | 从 ReadingProgress 读取，按时间倒序 |
| 最近刷题列表 | P1 | 从 ProblemAttempt 读取，按时间倒序 |
| 收藏书籍功能 | P2 | 收藏/取消收藏按钮 + 收藏列表 |
| 收藏题目功能 | P2 | 收藏/取消收藏 + 收藏列表 |
| 我的书库 | P2 | 用户导入的书籍管理入口 |
| 学习统计概览 | P2 | 阅读数、答题数、正确率等汇总 |
| AI 学习建议入口 | P3 | 基于学习数据的推荐占位 |

**验收标准**：
- 用户能注册和登录。
- 登录后能看到用户中心页面。
- 各模块在无数据时展示空态引导。
- 未登录用户访问 `/user` 时被引导至登录页。
- 所有数据来自真实 DB（非进程内存）。

## 4. 第三阶段：真实持久化

**状态**：未开始

**目标**：将所有 dev store（进程内存）迁移到 Prisma + PostgreSQL 持久化。

| 任务 | 优先级 | 说明 |
|------|--------|------|
| Book / Chapter 保存到 DB | P0 | 替代 dev store |
| Import 保存到 DB | P0 | 替代 `text-import-save-dev-store.ts` |
| Favorites 保存到 DB | P1 | 用户收藏数据持久化 |
| ReadingProgress 保存到 DB | P1 | 阅读进度真实记录 |
| UserActivity 保存到 DB | P1 | 最近阅读/刷题/问答/导入记录 |
| 数据库迁移自动化 | P2 | 开发环境自动 migrate |

**验收标准**：
- 重启应用后书籍、导入、收藏、进度数据不丢失。
- 所有写入通过 `packages/db` repository 层。
- DB 集成测试在 opt-in 环境下通过。

## 5. 第四阶段：LLM/API 接入

**状态**：未开始

**目标**：在 Reader 中接入真实 LLM provider，实现当前章节上下文感知问答。

| 任务 | 优先级 | 说明 |
|------|--------|------|
| Provider abstraction 完善 | P0 | `ai-core/llm` 抽象层 |
| 测试 provider | P0 | 用于开发测试的 mock/echo provider |
| Reader 当前章节问答 | P1 | 携带书籍/章节上下文向 LLM 提问 |
| 安全日志 | P1 | 记录调用但不保存 raw prompt/response |
| 成本和失败 fallback | P2 | 调用失败时用户可见错误提示 |
| 脱敏策略 | P2 | 不持久化 raw prompt/response |

**验收标准**：
- 用户在 Reader 中提问后能收到 LLM 回答。
- 回答结合当前章节上下文。
- 不硬编码 API 密钥（通过环境变量）。
- 调用失败时有 fallback 提示。
- 日志不含 raw prompt/response 到持久化存储。

## 8. 当前进度与下一轮建议

**当前阶段**：第一阶段基本完成，第二阶段待启动。

**下一轮（A375 或后续）建议二选一**：

1. **Web 用户中心与收藏功能**：schema/contract + 本地/dev-only UI 入口 v1。
   - 新增 User、Favorites 相关类型定义。
   - 实现用户中心页面骨架（各模块占位 + 空态引导）。
   - 实现收藏按钮 UI（暂不接真实 DB，使用 dev store 验证交互）。
   - 实现最近阅读/刷题列表（从现有 dev store 或 localStorage 读取 mock 数据）。

2. **Import dev store 到真实 DB 持久化**：opt-in repository v1。
   - 新增 Book/Chapter Prisma schema。
   - 实现 BookRepository 写入路径。
   - 将 `text-import-save-dev-store.ts` 迁移至 DB repository（opt-in guard 保护）。
   - 验证重启后数据不丢失。

**不推荐**：继续 Desktop 预览面板。

## 9. 长期方向（Phase 6+）

以下方向在 Web 主线基本闭环后推进：

- 更强的书籍解析：PDF、EPUB 导入。
- 更强的能力模型：知识图谱、遗忘曲线。
- 更强的题单系统：动态难度、错题复习。
- 更强的 Agent：后台长任务、工具编排。
- 更强的 Skill：自动发现重复任务、生成和发布 Skill。
- 更强的安全：权限沙箱、风险评分。
- 更强的社区：版本管理、评分、精选。
