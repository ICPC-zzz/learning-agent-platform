# 用户中心与收藏功能规格

> 从 A374 起规划。本文件定义用户中心、收藏、最近活动功能的详细规格，供后续 Codex 开发轮次参考。

## 1. 用户中心页面

### 1.1 页面路由

- `/user` 或 `/me` — 用户中心主页。
- 未登录用户访问时重定向至 `/login`，并携带 `redirect=/user` 参数。

### 1.2 页面布局

用户中心页面分为以下模块区域，每个模块独立加载和错误处理：

```
┌─────────────────────────────────────────┐
│  用户信息栏（昵称、头像、注册时间、学习天数）   │
├──────────────────┬──────────────────────┤
│  阅读进度概览      │  学习统计             │
│  （书籍数、章节数、  │  （答题数、正确率、     │
│   阅读时间估算）     │   能力雷达图占位）     │
├──────────────────┴──────────────────────┤
│  最近阅读（前 5 本，继续阅读按钮）          │
├─────────────────────────────────────────┤
│  最近刷题（前 5 题，答题结果标识）          │
├─────────────────────────────────────────┤
│  收藏书籍（前 5 本，查看更多入口）          │
├─────────────────────────────────────────┤
│  收藏题目（前 5 题，查看更多入口）          │
├─────────────────────────────────────────┤
│  我的导入书籍（管理入口）                   │
├─────────────────────────────────────────┤
│  AI 学习建议（占位 / 推荐入口）             │
└─────────────────────────────────────────┘
```

### 1.3 各模块状态处理

每个模块必须处理以下四种状态：

| 状态 | 展示 |
|------|------|
| 加载中 | 骨架屏或加载指示器 |
| 空态 | 引导文案 + 推荐操作链接（如"去浏览书籍"） |
| 错误 | 错误提示 + 重试按钮 |
| 有数据 | 正常渲染数据列表或统计 |

### 1.4 用户基本信息

- 昵称（可编辑）。
- 头像（默认占位 + 可上传）。
- 注册时间。
- 学习天数（注册至今）。

### 1.5 阅读进度概览

- 总阅读书籍数。
- 已完成章节数 / 总章节数。
- 估算总阅读时间（分钟/小时）。
- 最近阅读的书籍封面和进度条。

### 1.6 学习统计

- 答题总数。
- 正确率（百分比 + 趋势箭头）。
- 能力维度分数摘要（暂用简单文本/进度条展示，后续升级为雷达图）。
- 学习连续天数。

## 2. 收藏书籍功能

### 2.1 触发入口

- 书籍列表页：每本书卡片上的收藏按钮（心形图标）。
- 书籍详情页：封面旁的收藏按钮。
- Reader 页面：工具栏中的收藏按钮。

### 2.2 交互行为

- 点击收藏按钮：乐观更新为已收藏状态（填充心形），发送收藏请求。
- 再次点击：乐观更新为未收藏状态（空心心形），发送取消收藏请求。
- 请求失败时回滚 UI 状态，并展示错误提示。
- 未登录时点击：弹出提示"请先登录后收藏"，并提供登录链接。

### 2.3 收藏列表页面

路由：`/user/favorites/books` 或在用户中心内嵌展示。

- 按收藏时间倒序排列。
- 支持搜索（书名模糊匹配）。
- 支持标签筛选。
- 每项展示：封面占位图、书名、作者、标签、收藏时间、阅读进度。
- 点击书名跳转到书籍详情页。
- 每项右侧有取消收藏按钮。

### 2.4 数据模型方向

```typescript
interface BookFavorite {
  id: string;
  userId: string;
  bookId: string;
  sourcePage: string;  // 收藏来源页面（books list / book detail / reader）
  createdAt: Date;
}
```

## 3. 收藏题目功能

### 3.1 触发入口

- 题目页面：题目旁的收藏按钮。
- 答题结果页：结果面板中的收藏按钮。
- 题目列表页：每题的收藏按钮。

### 3.2 交互行为

- 与收藏书籍相同的乐观更新模式。
- 未登录时展示相同提示。

### 3.3 收藏列表页面

路由：`/user/favorites/problems` 或在用户中心内嵌展示。

- 按收藏时间倒序排列。
- 支持按难度筛选（入门/基础/进阶/挑战）。
- 支持按标签筛选。
- 每项展示：题目摘要、难度标识、标签、收藏时间、最近答题状态。
- 点击题目跳转到题目详情/答题页。
- 每项右侧有取消收藏按钮。

### 3.4 数据模型方向

```typescript
interface ProblemFavorite {
  id: string;
  userId: string;
  problemId: string;
  sourcePage: string;
  createdAt: Date;
}
```

## 4. 最近阅读

### 4.1 数据来源

从 `ReadingProgress` 表读取当前用户最近的阅读记录。

### 4.2 展示内容

- 按最后阅读时间倒序排列（前 5–10 条）。
- 每项展示：书名、最后阅读章节名、阅读时间、阅读进度百分比。
- "继续阅读"按钮跳转到上次阅读的章节位置。

### 4.3 数据模型方向

利用现有 `ReadingProgress` 实体，按 `updatedAt` 倒序查询。

## 5. 最近刷题

### 5.1 数据来源

从 `ProblemAttempt` 表读取当前用户最近的答题记录。

### 5.2 展示内容

- 按答题时间倒序排列（前 5–10 条）。
- 每项展示：题目摘要、所属书籍/章节、答题时间、答题结果（正确 ✅ / 错误 ❌ / 部分正确 ⚠️）。
- 点击跳转到题目详情或重新答题。

## 6. 最近问答

### 6.1 数据来源

从 `QuestionSession` 表读取当前用户最近的 AI 问答记录。

### 6.2 展示内容

- 按提问时间倒序排列。
- 每项展示：问题摘要（截断到 80 字符）、所在书籍/章节、提问时间。
- 点击跳转到问答上下文（书籍章节 + 问答历史）。

## 7. 最近导入

### 7.1 数据来源

从 `ImportTask` 或 `Book` 表（来源为 `import`）读取当前用户的导入记录。

### 7.2 展示内容

- 按导入时间倒序排列。
- 每项展示：书名、导入时间、导入状态（成功/处理中/失败）。
- 成功：点击跳转到书籍详情。
- 失败：展示失败原因和重试入口。

## 8. DB 持久化设计方向

以下为数据模型设计方向，具体 schema 在开发轮次中实现，不在此文档轮中落地。

### 8.1 新增/修改实体方向

- **User**：新增昵称、头像、注册时间等字段。
- **Favorites**：新表，包含 userId、targetType（book/problem）、targetId、sourcePage、createdAt。
- **ReadingProgress**：已有实体，用于最近阅读查询。
- **ProblemAttempt**：已有/新增实体，用于最近刷题查询。
- **QuestionSession**：已有/新增实体，用于最近问答查询。
- **ImportTask**：已有实体，用于最近导入查询。

### 8.2 查询模式

- 最近活动统一按 `createdAt` 或 `updatedAt` 倒序，支持分页（offset/limit 或 cursor-based）。
- 收藏列表支持搜索（LIKE 查询或全文索引）和筛选（WHERE 条件）。
- 各模块独立查询，避免一次请求加载所有数据（影响页面首屏速度）。

### 8.3 安全约束

- 所有查询必须限定当前用户 ID（从 session 获取），禁止越权访问其他用户数据。
- 未登录用户的所有 API 调用返回 401。
- 收藏去重：同一用户对同一目标只能有一条收藏记录。
- 软删除：收藏取消时可考虑软删除（保留记录用于分析），或硬删除（用户期望的完全移除）。

## 9. 未登录状态安全处理

- 所有收藏按钮在未登录时仍展示（让用户知道功能存在），但点击时展示登录引导弹窗。
- 用户中心路由在未登录时重定向至登录页，URL 携带 `redirect` 参数。
- API 层对所有需要用户身份的端点返回 401，前端统一处理并展示登录引导。
- 不做 localStorage 假收藏或假进度（避免用户登录后发现数据丢失的糟糕体验）。
- 登录和注册页面需简洁，支持邮箱/密码或 OAuth（GitHub/Google）等最小方案。

## 10. 开发阶段建议

### 开发阶段 1：用户系统 + 中心页面骨架（推荐 A375）

- 实现最小可用 auth（NextAuth 或类似，邮箱/密码或 OAuth）。
- 用户中心页面路由和骨架布局。
- 各模块占位 + 空态引导。
- 未登录重定向逻辑。

### 开发阶段 2：收藏功能 UI + dev store

- 收藏按钮 UI 组件（书籍 + 题目）。
- 乐观更新交互逻辑。
- 收藏列表页面（使用 dev store 或 mock 数据）。
- 未登录提示逻辑。

### 开发阶段 3：真实 DB 持久化

- Prisma schema 新增 Favorites 及相关实体。
- Repository 层实现收藏/取消收藏/查询。
- 将 dev store 迁移至 DB。
- 最近阅读/刷题查询从真实表读取。

### 开发阶段 4：完善与美化

- 学习统计真实数据接入。
- AI 学习建议模块。
- 各模块交互细节优化。
- 移动端响应式适配。
