# Codex Rules

本文件是 Codex 每轮默认读取的小规则文件。长历史、审计全文和参考分析默认不放在这里。

## 每轮开始

- 先确认本轮任务范围、允许修改目录、禁止修改目录和验收标准。
- 只读取本轮任务需要的文档和源码。
- 默认不读取所有历史 Axxx 文档。
- 默认不读取 `docs/status/PROJECT_COMPLETION_SUMMARY.md`，除非任务要求审计、阶段总结、文档压缩或全局规划。
- 默认不读取 `docs/reference-analysis`，除非任务明确要求参考分析。

## 修改原则

- 小步修改，一轮只处理一个明确任务。
- 禁止超范围实现。
- 禁止顺手修无关问题。
- 禁止扩大模块边界。
- 禁止无边界重构。
- 修改前先说明计划。
- 修改后必须跑与任务匹配的验证。

## AI 与安全

- UI 层不得绕过 repository、AI core、权限或安全边界。
- 不把 preview-only、mock-only、disabled-by-default 能力写成真实上线能力。
- 不默认调用真实 LLM provider。
- 不默认执行真实工具。
- 不保存或输出 raw prompt、raw response、API key、数据库密码、token 或 secret。

## 最终输出

每轮最终输出必须包括：

- 修改文件。
- 验证命令。
- 验证结果。
- 风险。
- 下一步建议。
- 项目总进度。

如果执行了文件移动，必须列出：原路径 -> 新路径 -> 移动原因。

## 停止条件

如果上下文过长、额度不足、文档或代码状态无法干净完成，停止当前实现，说明已完成部分和风险，并要求用户开 Axxx+ 补救对话。
