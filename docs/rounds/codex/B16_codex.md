# B16 Codex：题目画像中文化与代码分析超时收敛

日期：2026-07-14

## 问题

题目画像的规则估算分支直接返回了英文说明、约束和标签键，界面又直接展示这些内部值。代码分析方面，上轮并行化已经提交，但 B14 的运行时限制文件和工作流接入仍只存在于工作区，没有进入远端分支；此外，结构化输出格式修复会重新使用完整请求超时。

## 改动

- 规则估算、用户填写标签和模型标签的固定说明改为中文；保留 Codeforces、Rating 等专有名词。
- 新增题目画像展示格式化器：内部仍使用标准 Codeforces 标签键，界面显示中文名称并保留英文键作为辨识信息。
- 题目画像页面统一格式化标签、所需知识、关键约束、推断说明和不确定性提示。
- 纳入代码分析运行时限制：请求超时限制在 120–150 秒，输出限制为最多 2048 tokens。
- 结构化生成的首次请求和 JSON 格式修复共享同一个总时限，修复请求只使用剩余时间。
