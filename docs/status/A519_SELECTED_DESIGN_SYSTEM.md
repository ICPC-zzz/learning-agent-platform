# A519 Selected Design System

日期：2026-06-29
选择结果：方案 C，Academic Technology Studio

## 1. 设计方向

本轮用户选择方案 C。普通用户端 Web 页面统一采用“学术技术工作室”风格：浅色纸感背景、森林绿主色、靛蓝/珊瑚/天空蓝作为功能辅助色，整体更像长期学习工作台，而不是后台控制台或接口文档页面。

本风格已作为普通用户端默认视觉方向落到以下页面：

- 首页 `/`
- 文章 `/articles`
- 题目中心 `/problems`
- AI 助手 `/ai`
- 个人 `/user`
- 登录 `/auth/login`
- 注册说明 `/auth/register`

后台 `/admin/**` 不纳入本轮视觉改造，只做冒烟检查，避免把后台管理端改成普通用户端风格。

## 2. 核心视觉 Token

- 页面背景：`#f7f8f5`，叠加浅绿色与靛蓝径向光场。
- 主卡片：`rgba(255, 255, 252, 0.92)`，8px radius，弱阴影。
- 主色：`#0f6b48`，用于主按钮、当前标签、关键状态。
- 强主色：`#0a4f36`，用于 hover / focus。
- 辅助色：`#4f63d9`、`#e9684a`、`#3f7dd9`。
- 页面宽度：普通内容 `1280px`，首页大屏 `1380px`。
- 卡片圆角：保持 8px，不做大圆角营销卡片。

## 3. 首页

首页是本轮重点页面，已改为完整第一屏体验：

- 左侧：大标题“专注建模，持续成长”、功能入口状态、主 CTA。
- 右侧：知识图谱视觉资产 `apps/web/public/a519/academic-knowledge-map.png`。
- 动效：知识图谱使用轻量浮动动画 `a519-map-float`，并支持 `prefers-reduced-motion` 关闭。
- 数据口径：避免硬编码伪个人成绩，首页展示“可阅读/可进入/可提问/可查看”等入口状态。

## 4. 组件规则

- `PageHero` 与首页 CTA 样式解耦，使用 `learningHeroActions` 承载指标 pill。
- `MetricPill` 允许换行，避免移动端长日期撑宽页面。
- 文章收藏按钮在小屏变为紧凑图标按钮，保留 `aria-label` 与 `title`。
- AI 页将最终回答/对话主体放大，模型、记忆、执行链收束为辅助入口。
- 文章页、题目页、个人页统一使用浅色卡片、绿色当前态和克制边框。

## 5. 响应式要求

已覆盖 390px 移动端和 1440px 桌面端：

- 首页标题固定为两行，避免窄屏裁切。
- 首页 CTA 在窄屏保持两列，但按钮文案缩短为“问 AI 教练”。
- 文章卡片头部、日期徽章、收藏按钮均可在窄屏内换行或收缩。
- AI 页 tab 横向滚动，不撑宽页面。
